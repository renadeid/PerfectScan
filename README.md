# Perfect Scan — Radiology Center Portal

بوابة عربية (RTL) خاصة بمركز **Perfect Scan للأشعة — د. عيد رمضان البيطار**، متصلة بـSupabase لتسجيل الدخول وعزل بيانات كل مريض.

## رحلة المريض

- دخول بوابة المريض مباشرة إلى مركز Perfect Scan.
- اختيار نوع الفحص: MRI، CT، X-Ray، سونار ودوبلر، هشاشة عظام، أو بانوراما أسنان.
- اختيار فرع الصوالحة أو فرع عرابي.
- اختيار اليوم والوقت، مع عرض تعليمات التحضير المناسبة للفحص.
- متابعة المواعيد القادمة والزيارات السابقة.
- مشاهدة حالة التقرير، فتح التقرير الطبي المعتمد، وعرض صور الأشعة.

## إدارة المركز

- Dashboard للفحوصات والتقارير وحالة أجهزة التصوير.
- إدارة حجوزات الفرعين وحالة حضور المريض.
- مراجعة واعتماد تقارير الأشعة قبل ظهورها للمريض.
- ملفات المرضى وسجل الفحوصات.
- إدارة الفروع والأجهزة وساعات العمل.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادم ملفات محليًا على المنفذ `4173` ثم افتح `http://localhost:4173`.

## إعداد Supabase

1. افتح `supabase/schema.sql`.
2. شغّل الملف كاملًا مرة واحدة من **Supabase Dashboard → SQL Editor**.
3. أنشئ حسابك من الموقع.
4. اتبع `supabase/SETUP.md` لتحويل حسابك إلى Admin.

النظام يستخدم:

- Supabase Auth لتسجيل الدخول وإنشاء حسابات المرضى.
- Postgres + Row Level Security لعزل بيانات كل مريض.
- Private Storage لحفظ تقارير PDF والصور.
- Edge Function آمنة ليتمكن الـAdmin من إنشاء حساب مريض بكلمة مرور مؤقتة.
- Publishable key فقط داخل المتصفح؛ لا توجد Secret keys في المشروع.

## تنبيه

شغّل واختبر النظام أولًا ببيانات تجريبية. قبل إدخال بيانات طبية حقيقية، راجع متطلبات حماية وخصوصية البيانات المطبقة على المركز، فعّل MFA لحساب الإدارة، وراجع نتائج **Security Advisor** داخل Supabase.
